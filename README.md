# Filsa social videos

Public 1080x1920 marketing videos for Filsa Business social posts (Instagram Reels, Facebook Reels, TikTok, YouTube Shorts), scheduled via Metricool.

## Hook covers (from 2026-10-26)

- `c/filsa-<id>-<lang>-cover.jpg`: 1080x1920 hook cover, sent to Metricool as the post's cover (`videoThumbnailUrl`). The headline sits inside the middle 3:4 band so the Instagram profile grid shows it whole.
- `v/filsa-<id>-<lang>-9x16-1080-hook.mp4`: the file to post. It opens on the cover for 0.8 s, then fades into the video. Post these, not the plain `-1080.mp4` files.
